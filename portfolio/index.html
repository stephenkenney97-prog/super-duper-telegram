Market Seismograph

Standalone browser demo

Crypto price movement ripples across 3D terrain. The display identifies Coinbase, CoinGecko, or simulated data. Its seismic magnitude is an artistic index.

Open market demo →
How to run

Serve this folder over HTTP, then open the demo. The 3D libraries and live price feeds need internet access; a simulated feed is available when price requests fail.

03

Japan Earthquake Map

Python tool · plotting dependencies required

Fetches the preceding 24 hours from USGS and labels the exact UTC window. Includes neighboring waters. Network failures stop the map rather than showing sample events.

Download Python source
How to run
python -m pip install -r source/requirements-maps.txt
python source/earthquake_map.py --output japan-earthquakes.png
